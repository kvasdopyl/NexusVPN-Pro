# NexusVPN Pro 2.0

**NexusVPN Pro** — профессиональный VPN-клиент для Windows с интеллектуальной самообучающейся
маршрутизацией (Smart Auto-Split Tunneling) и поддержкой всех современных протоколов.

## Установка

1. Откройте на GitHub раздел **Releases** и скачайте **NexusVPN-Pro-Setup-….exe**.
2. Запустите установщик. Программа встанет в `C:\Program Files\NexusVPN Pro`, а значки появятся
   на рабочем столе и в меню «Пуск». Скачанный файл после установки можно удалить.
3. Откройте «Серверы» → «+ Добавить», вставьте подписку и нажмите **ВКЛ**.

> Windows SmartScreen может показать «неизвестный издатель», потому что программа не подписана
> сертификатом: нажмите «Подробнее» → «Выполнить в любом случае».

## Обновления

- Программа проверяет новые версии каждые 6 часов. Если версия вышла, появляется уведомление в трее
  и зелёная плашка на главной. Можно нажать «Обновить» или включить установку без вопросов
  (страница «Обновления»).
- Ядра sing-box, Xray и mihomo проверяются раз в сутки и тоже присылают уведомление.
- При обновлении настройки, подписки и изученные правила сохраняются.

## Удаление

- Windows: «Параметры» → «Приложения» → «Установленные приложения» → NexusVPN Pro → «Удалить».
- Или в самой программе: **«О программе и удаление»** → «Удалить программу…».

В обоих случаях убирается всё: файлы, ярлыки, автозапуск, правила Брандмауэра, подключения IKEv2,
системный прокси возвращается как был. Настройки можно сохранить или удалить вместе с программой.

## Три режима (кнопки на главной)

| Режим | Что делает |
|---|---|
| **Всё через VPN** | Весь трафик идёт через VPN, кроме локальной сети и вашего списка «Напрямую» |
| **Своя маршрутизация** | Через VPN идёт только то, что вы вписали: домены, IP, подсети, программы. Можно вставлять сотни строк сразу или импортировать из файла |
| **Умная маршрутизация** | Программа сама находит заблокированные сайты и программы, проверяет их через VPN и запоминает |

Формат строк в «Своей маршрутизации»: `example.com`, `*.example.com`, `full:api.site.com`,
`keyword:google`, `1.2.3.4`, `10.0.0.0/8`, `2001:db8::/32`, `Telegram.exe`, `https://site.com/путь`.
Изменения применяются без перезапуска VPN.
Кнопки **«Выбрать из запущенных программ…»** и **«Выбрать из открытых сайтов…»** добавляют
программы и сайты в нужный список одним нажатием.

Рядом с каждым параметром есть кнопка **«?»** с объяснением на русском.

## Своя маршрутизация

Сверху — кнопки сервисов (Discord, YouTube, Telegram, ChatGPT…): нажал — включено и выделено зелёным, нажал ещё раз —
выключено. Ниже два списка, «Через VPN» и «Напрямую», с кнопками **«+ Программа…»**, **«+ Сайт…»** и **«+ Вручную…»**.
Программу выбирают из запущенных, сайт — из открытых или вписывают адрес. Всё применяется сразу, без кнопки
«Сохранить» и без перезапуска VPN. «Убрать» и «Перенести» активны, только когда что-то выделено.

## Игры

Отдельная вкладка **«Игры»**: готовые наборы (Call of Duty, Battle.net, все игры Steam, CS2, Dota 2, PUBG, Apex,
Epic/Fortnite, Riot, EA, Ubisoft, Xbox, Мир танков, War Thunder, Tarkov, HoYoverse, VK Play, Minecraft,
Roblox, Rockstar, GOG). Для каждой игры три кнопки в строке: «Не трогать», «Напрямую», «Через VPN»; выбранная закрашена, изменение применяется сразу. Свою игру можно
добавить из запущенных программ или указать её папку. По умолчанию все игры выключены.

## Мимо VPN — значит мимо программы

Настройки → «Трафик мимо VPN» → **«Мимо программы»** (по умолчанию, режим TUN). В туннель попадают
только адреса, которым нужен VPN: сайты из списков (через FakeIP), Telegram, голосовые серверы Discord
и программы, отправленные через VPN. Игры, сайты из «Напрямую» и сайты, которые умная маршрутизация
отнесла к прямым, идут сразу через сетевую карту, и программа этот трафик даже не видит.
Если нужны игры «Через VPN» или программы, которые ходят в сеть по IP, выберите «Через программу».

В режиме **«Системный прокси»** голос Discord и звонки Telegram тоже работают: для них поднимается
маленький туннель только на их адреса (нужен запуск от администратора).

## Протоколы

| Протокол | Чем работает |
|---|---|
| VLESS (Reality/Vision/gRPC/WS/HTTPUpgrade), VMess, Trojan, Shadowsocks/SS-2022, Hysteria2, TUIC, WireGuard, AnyTLS, SOCKS5, HTTP(S) | sing-box |
| VLESS **XHTTP** | Xray (подключается автоматически) |
| **AmneziaWG 1.0 / 1.5 / 2.0 / 3.0 / 3.1** | mihomo, без драйверов. Версия определяется по `.conf` (HeaderProtectionKey, ContentPaddingAddition, S3/S4, диапазоны H1–H4, I1–I5) |
| **OpenVPN** (.ovpn) | официальный OpenVPN; установка одной кнопкой в «Обновления». Перехват всего трафика сервером (redirect-gateway) отключается: маршрут выбирает NexusVPN |
| **IKEv2** (EAP или сертификат) | встроенный IKEv2 Windows с раздельным туннелированием; можно импортировать сертификат CA |

Поддерживаются подписки 3x-ui, Marzban, Remnawave, Hiddify, Clash/Mihomo YAML, sing-box JSON
и ссылки AmneziaVPN `vpn://`.

**Подписки:** добавить, изменить (ссылка, название, User-Agent, интервал, вкл/выкл), удалить,
обновить одну или все.
**Серверы:** добавить ссылку или конфиг, изменить (двойной щелчок), скопировать ссылку, удалить,
включить или выключить галочкой. Изменённый сервер из подписки переносится в «Ручные», чтобы
обновление подписки не стёрло правку.

## Discord и долгая работа

- Отдельная вкладка **«Discord»**: одна кнопка «Discord через VPN», выбор сервера для голоса, состояние звонка
  в реальном времени и подсказки, что проверить в самом Discord. Работает в любом режиме, в том числе
  в «Своей маршрутизации»: голос (UDP 50000–65535 и 19294–19344 на 353 подсетях Cloudflare, i3D.net и Discord)
  заходит в туннель по адресу, даже если сайты идут мимо программы.
- Голос идёт через свою группу серверов: сначала те, что передают UDP как UDP (Hysteria2, TUIC, WireGuard,
  AmneziaWG, Shadowsocks). Смена основного сервера и автопереключение при сбое **не трогают звонок**; если сервер
  голоса перестал отвечать дважды подряд, звонок сам переезжает на работающий за 1–2 секунды.
- Обновления ядер и подписок откладываются, пока идёт звонок.
- Watchdog перезапускает ядра и туннели; при сбое сервер переключается автоматически.
- Соединения восстанавливаются после сна и смены сети; память ядра ограничена; журналы ротируются.
- Автозапуск без окна UAC; после перезагрузки VPN подключается сам.

## Автозапуск

Галка «Запускать вместе с Windows» создаёт задачу в Планировщике: старт без запроса прав, в том числе от батареи,
без ограничения по времени. При таком запуске VPN **подключается сам**, даже если в прошлый раз его выключили
(если сеть ещё не поднялась, программа повторяет попытку). Запуск вручную подключает, только если VPN был включён.
